# Candidate review inputs

Preserve the candidate digest, evaluation-set revision/digest, source evidence
IDs, baseline/target comparison, clean-reset identities, critical-check results,
failure classes, counterexamples and independent reviewer decision. Review the
actual bilingual lesson and its version, role, surface and operation scope.

The reviewer should be able to reject a plausible but unproven claim, a stale
candidate, contaminated holdout or omitted negative result. A favorable average
does not waive any critical failure. Invalid, incomplete, revoked or
author-supplied success records cannot establish promotion.

Keep evaluator-owned state outside the author's write grant. Same-machine local
files and identity labels alone are not an adversarial isolation mechanism;
enforce the separation with the session's actual tool/workspace permissions.
