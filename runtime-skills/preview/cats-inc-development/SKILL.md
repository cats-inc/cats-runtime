# Cats Development

Turn the current authorized improvement into a reviewable source change and
evidence. This preview supplement supplies procedure; it grants no source,
credential, model-usage, publication or other-machine access.

Locate the owner's admitted source workspace. Read its AGENTS.md, your own
agent instructions and the governing member plan before editing. Cats-one owns
launch/workspace composition; Runtime owns provider execution and managed skills;
Platform owns Desktop, product flows and knowledge; Apps owns utility packages.
Follow the owning member's current contracts rather than a copied API inventory.

Identify the installed controller and candidate separately. Record repository
revisions, dirty state, branch, task/grant and success checks. Keep candidate
worktrees, profiles, listeners and process handles separate from the installed
controller. Inspect ownership before retry or cleanup; preserve unrelated edits
and retained evidence. If isolation or the required tool is unavailable, report
that specific boundary and continue only work that does not depend on it.

Implement one bounded slice, then run the relevant contract/build checks in the
owning checkout. Keep independent evaluation inputs outside the author's write
scope. A worker's statement is a proposal until tests or authoritative operation
results establish it. Obtain review from a different authorized agent/reviewer;
never label your own diff independently reviewed. Existing authorization remains
valid; ask only for genuinely missing scope or permissions.

Before the next slice, update the governing plan with the branch/revision, exact
change, passing and failed checks, pending work and next command or entry point.
Commit to the authorized feature branch when granted. Main integration uses the
normal PR/CI process; do not infer permission to publish, merge or upgrade the
installed app. For a longer interruption, use the optional
[checkpoint fields](references/checkpoint.md).

Pass a sanitized, version-scoped lesson and its evidence identifiers to
cats-practice-and-distill. Keep raw transcripts, private paths and secrets out
of knowledge intended for release. A source fix and a verified product lesson
are separate deliverables; neither proves the other.
