# Resuming an interrupted slice

Store this information in the owning repository's existing plan, not in the
skill package or an untracked chat-only note:

- Authorized objective, repository and operation scope; consumed live approvals.
- Feature branch, base and latest committed revision; intentional uncommitted work.
- Controller/candidate identity and owned workspace/profile/process handles.
- Observed results with commands, revisions and sanitized artifact references.
- Failed, skipped or incomplete checks and the practical limits of passing ones.
- Next independent step and any action awaiting authorization or external state.

On resume read the workspace/member instructions and plan, inspect actual Git
and supported process/task state, and reconcile the checkpoint before retrying a
mutation. A stale note is not evidence that a process stopped or a commit landed.
