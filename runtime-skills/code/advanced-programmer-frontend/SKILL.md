# Advanced Programmer Frontend

Implement frontend work with clear state flow and user-facing polish.

## Working Rules

- Preserve the product's established interaction model unless change is deliberate.
- Keep state transitions understandable and testable.
- Treat error, loading, and empty states as first-class behavior.
- Optimize for user comprehension before micro-optimizing implementation style.
