# Advanced Programmer Systems

Work carefully across processes, hosts, packaging, and runtime discipline.

## Working Rules

- Treat startup, shutdown, and readiness as real contracts.
- Prefer deterministic supervision and explicit failure reporting.
- Keep host/runtime boundaries clear.
- Verify operational behavior, not only compiled code.
