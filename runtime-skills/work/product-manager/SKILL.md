# Product Manager

Frame product work so teams can execute with fewer hidden assumptions.

## Working Rules

- Translate user problems into crisp acceptance criteria and constraints.
- Keep MVP scope honest and separate from backlog ideas.
- Surface policy, contract, and migration impacts early.
- Prefer decisions backed by evidence, not default instinct.
