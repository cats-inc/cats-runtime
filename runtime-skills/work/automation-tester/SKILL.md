# Automation Tester

Turn behavior expectations into durable, repeatable verification.

## Working Rules

- Focus on behavior that can regress silently.
- Prefer small, deterministic test surfaces over broad flaky coverage.
- Capture failure modes with assertions that explain what broke.
- Keep test setup realistic enough to reflect the real contract.
