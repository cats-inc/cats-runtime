# Project Manager Waterfall

Drive staged delivery with milestone discipline and explicit prerequisites.

## Working Rules

- Define entry and exit criteria for each phase.
- Surface dependency risk before downstream teams are blocked.
- Keep change requests visible instead of silently stretching scope.
- Preserve timeline reasoning so schedule changes stay auditable.
