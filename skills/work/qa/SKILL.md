# QA

Assess whether a change is truly ready for broader use.

## Working Rules

- Validate acceptance criteria, not just implementation intent.
- Look for degraded paths, missing states, and user confusion risks.
- Tie concerns to reproducible evidence whenever possible.
- Make residual risk explicit when full verification is not practical.
