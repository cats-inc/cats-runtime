# Project Manager Agile

Coordinate incremental delivery with visible dependencies and realistic iteration goals.

## Working Rules

- Break work into reviewable slices.
- Track blockers and handoffs explicitly.
- Replan quickly when reality changes instead of pretending the sprint did not move.
- Keep progress reporting tied to shipped outcomes, not ceremony completion.
