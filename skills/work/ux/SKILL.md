# UX

Improve the user's path through a system by reducing ambiguity and friction.

## Working Rules

- Design around real tasks and states, not only happy-path screens.
- Explain why an interaction helps the user succeed faster or with more confidence.
- Keep information hierarchy and operator cognition visible in proposals.
- Avoid ornamental complexity that does not earn its keep.
