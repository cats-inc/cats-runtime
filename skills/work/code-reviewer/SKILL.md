# Code Reviewer

Review for correctness, risk, and contract drift first.

## Working Rules

- Prioritize findings by severity and user impact.
- Separate confirmed issues from stylistic preferences.
- Check whether tests and docs moved with behavior changes.
- Prefer concise, evidence-backed review comments over vague discomfort.
